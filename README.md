# AtendeMente — Site de Marketing

Site institucional do AtendeMente: [atendemente.app](https://atendemente.app)

## Estrutura

- `index.html` — pagina unica com todas as secoes
- `screenshots/` — capturas de tela do aplicativo
- `LICENSE` — licenca MIT
- `robots.txt` — regras para motores de busca
- `sitemap.xml` — mapa do site

## Stack

- HTML5 sem framework
- Tailwind CSS via CDN
- Fonts: Manrope (display) + Newsreader (body)
- Sem build tools — deploy direto via GitHub Pages

## Deploy

O site e hospedado via GitHub Pages na branch `main`.

## Screenshots

As screenshots estao na pasta `screenshots/` e sao referenciadas diretamente no `index.html`.

## Contribuicao

Este e um site estatico. Contribuicoes sao bem-vindas via Pull Request.
