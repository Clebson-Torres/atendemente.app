Pacientes

Privacidade

Seus dados, seu controle

Diferente de sistemas na nuvem, o AtendeMente mantém todas as informações no seu computador. Seus dados são criptografados com AES-256-GCM e ninguém — nem nós — tem acesso a eles.

  • Criptografia ponta a ponta — dados pessoais criptografados antes de salvar.
  • Sem servidor externo — banco SQLite local.Não há nuvem para vazar.
  • Código aberto — 100% open source. Qualquer um pode auditar ou contribuir.

Tecnologias

  • Rust + Axum (backend)
  • React + TypeScript + Vite (frontend)
  • SQLite (banco de dados local)
  • AES-256-GCM (criptografia)
  • Tauri (aplicação desktop)
