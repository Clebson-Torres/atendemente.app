Funcionalidades

Tudo que você precisa no dia a dia

Um sistema completo, pensado para a rotina do consultório particular.

Cadastro de Pacientes

Gerencie dados pessoais, histórico de saúde e medicamentos. Tudo criptografado e seguro.

Agenda de Atendimentos

Visualização mensal com filtros por status, confirmação e séries recorrentes. Nunca perca um horário.

Prontuário por Sessão

Registre anotações de cada atendimento com anexos. Recupere rapidamente o histórico do paciente.

Controle Financeiro

Registre pagamentos por consulta com status (pago/pendente/cancelado) e método (PIX, cartão, dinheiro).

Dashboard e Relatórios

Gráficos de atendimentos mensais e receita. Exporte dados em CSV e prontuários em PDF/ZIP.

Privacidade Total

Dados criptografados com AES-256-GCM. Nenhum dado sai do seu computador. Sem nuvem, sem assinatura.

Privacidade

Seus dados, seu controle

Diferente de sistemas na nuvem, o AtendeMente mantém todas as informações no seu computador. Seus dados são criptografados com AES-256-GCM e ninguém — nem nós — tem acesso a eles.

  • Criptografia ponta a ponta — dados pessoais são criptografados antes de serem salvos no banco local.
  • Sem servidor externo — o banco de dados SQLite roda localmente. Não há "nuvem" para vazar.
  • Código aberto — o projeto é 100% open source. Qualquer um pode auditar, contribuir ou modificar.

Tecnologias utilizadas

  • Rust + Axum (backend)
  • React + TypeScript + Vite (frontend)
  • SQLite (banco de dados local)
  • AES-256-GCM (criptografia)
  • Tauri (aplicação desktop)
